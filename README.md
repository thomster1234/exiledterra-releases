# ExiledTerra: test builds

Player downloads for the ExiledTerra closed alpha test. Get the newest build under **[Releases](../../releases/latest)**.

- **macOS (Apple Silicon):** `ExiledTerra-mac.zip`
- **Windows:** `ExiledTerra-win.zip`

You need an **invite code** from the host to create an account. Each release's `PLAYERS.txt` says how to start the game and connect.

Alpha builds are unsigned. On first launch:
- **macOS:** right-click the app and choose **Open**.
- **Windows:** click **More info**, then **Run anyway**.

This repository only hosts downloads; the game's source code is private.
